# HTML-Entwickler

## Was ist HTML?

HTML bedeutet Hypertext Markup Language. Damit erstellt man die Struktur einer Webseite.

## Aufgaben eines HTML-Entwicklers

- Texte und Überschriften auf einer Webseite erstellen.
- Bilder und Links einfügen.
- Formulare erstellen.
- Inhalte übersichtlich strukturieren.

## Verwendete Werkzeuge

- Visual Studio Code
- HTML
- Webbrowser
