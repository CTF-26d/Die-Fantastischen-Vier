# Web Development – Webentwicklung

## 1. Was ist Web Development?
Web Development bedeutet die Entwicklung und Erstellung von Webseiten und Webanwendungen. Dabei werden verschiedene Programmiersprachen und Technologien verwendet.

## 2. Frontend Development
Frontend ist der sichtbare Teil einer Webseite, mit dem Benutzer direkt interagieren.

- **HTML:** Erstellt die Struktur einer Webseite.
- **CSS:** Verantwortlich für das Design und Layout.
- **JavaScript:** Macht Webseiten interaktiv und dynamisch.

## 3. Backend Development
Backend ist der technische Teil einer Webseite, der im Hintergrund arbeitet. Es verarbeitet Daten, verwaltet Benutzerkonten und kommuniziert mit Datenbanken.

Beispiele für Backend-Technologien sind Python, PHP, Java und Node.js.

## 4. Responsive Web Design
Responsive Web Design sorgt dafür, dass eine Webseite auf verschiedenen Geräten gut aussieht und funktioniert, zum Beispiel auf Computern, Tablets und Smartphones.

## 5. Datenbanken
Datenbanken speichern und verwalten Informationen einer Webanwendung, zum Beispiel Benutzerdaten, Produkte und Bestellungen.

Beispiele sind MySQL und PostgreSQL.

## 6. Sicherheit im Web Development
Die Sicherheit einer Webseite ist sehr wichtig. Entwickler müssen Benutzerdaten schützen, sichere Passwörter verwenden und Sicherheitslücken vermeiden.

## 7. Ziel unseres Unternehmens
Unser Ziel ist es, moderne, benutzerfreundliche und sichere Webseiten für Unternehmen und Privatpersonen zu entwickeln.
